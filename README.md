En primer lugar, esto se realizó utilizando CSS y HTML. Otro punto que quiero explicarles es cómo publicar nuestra página web. Para ello, utilizamos Netlify, una plataforma que permite alojar páginas web.

Primero, debemos subir nuestro código HTML y los archivos necesarios a Netlify. Luego, la plataforma nos proporciona una URL que podemos utilizar para acceder a nuestra página desde un navegador, incluso desde un celular. Además, la conexión es segura porque utiliza HTTPS.

ENG: 
First of all, this project was created using CSS and HTML. Another point I would like to explain is how to publish our website. For this purpose, we used Netlify, a platform that allows us to host websites.

First, we upload our HTML code and the necessary files to Netlify. Then, the platform provides us with a URL that we can use to access our website through a browser, even from a mobile phone. In addition, the connection is secure because it uses HTTPS.
